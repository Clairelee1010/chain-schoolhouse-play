# Block School Explorer

請幫我製作一個單頁式的「區塊鏈小學堂互動學習 Web App」。這是一個專為初學者設計的互動網頁，以下是完整的文案內容、測驗題庫以及我要求的視覺與互動邏輯：

### 🎨 視覺風格與整體配置

1. 現代科技簡約風（類似 Apple/Notion 質感），主色調為深藍（科技感）、靛藍與亮綠色（代表區塊鏈與合規安全）。支援流暢的深色模式切換（Dark Mode）。

2. 頂部有一個「學習進度條」，當使用者閱讀完卡片或做完測驗時，進度條會即時推進。

### 📚 第一階段：四大主題互動學習卡（Flashcards）

請將以下四大主題做成「可點擊翻轉的 3D 互動字卡 (Flip Cards)」。正面顯示「痛點標題與主Icon」，點擊或懸停時流暢翻轉至背面，顯示「並列重點、金句與學習教室提醒」。

【主題一：穩定幣入門與種類解密】

* 正面：價格天天像坐雲霄飛車？教你用穩定幣打造數位資產的避風港！(Icon: ⚖️)

* 背面：

  - 法幣抵押型穩定幣：由美元或短期美債等法定貨幣資產 1:1 100% 儲備發行（如 USDT、USDC）。金句：「每一顆穩定幣背後，都有真正的美元在撐腰！」

  - 加密資產抵押型穩定幣：通常採用超額抵押機制來維持價格穩定（如 USDS、DAI）。金句：「用更多的鏈上資產做擋箭牌，抗跌耐震更安心！」

  - 合成美元／對衝型穩定幣：透過現貨資產與衍生品對衝策略來降低波動（如 USDe）。金句：「靠對衝策略擋住風浪，不放現貨也能維持平穩！」

  - 演算法穩定幣：純粹透過演算法調節市場供需（如 Luna/UST）。金句：「沒有資產儲備只靠代碼演算法，市場恐慌時極易面臨脫鉤考驗！」

  - 💡 學習教室：

    * 穩定幣 (Stablecoin)：價格錨定法定貨幣的加密貨幣。

    * 錨定 (Peg)：將數位資產與另一項資產按固定比例連動。

    * 脫鉤 (Depeg)：穩定幣價格明顯偏離原本錨定的價格。

【主題二：監管法規與儲備安全防線】

* 正面：發行商口袋到底有沒有錢？帶你一眼看懂監管法規與儲備真相！(Icon: 📜)

* 背面：

  - 國際監管法規 (GENIUS Act / MiCA)：美國與歐盟出台的穩定幣專法。金句：「有了專法嚴格把關，野蠻生長的時代正式終結！」

  - 100% 足額儲備 (Full Reserve)：每發行 1 元穩定幣，必須有等值的現金或高品質流動資產作儲備。金句：「實打實的資產備查，隨時兌現不卡關！」

  - 禁止重複抵押 (No Rehypothecation)：嚴禁將客戶的抵押資產再次轉借或二次抵押。金句：「你的錢就是你的錢，絕不許被私下挪用！」

  - 儲備證明與第三方審計：透過獨立會計師核驗與完整審計，確認資產真偽。金句：「公開透明的帳本，才是信任的最強基石！」

  - 💡 學習教室：

    * GENIUS Act：美國 2025 年簽署的聯邦層級支付型穩定幣專法。

    * 儲備簽證報告 (Attestation Report)：外部會計師針對特定日期儲備資料進行核驗的報告。

    * 重複抵押 (Rehypothecation)：把客戶的抵押品拿去二次抵押或借貸的行為。

【主題三：RWA 與傳統資產鏈上化】

* 正面：美債、股票也能在區塊鏈上買賣？一文看懂真實世界資產 (RWA) 代幣化！(Icon: 🌐)

* 背面：

  - 真實世界資產 (RWA)：將股票、美債、房地產等傳統金融資產「代幣化」搬上區塊鏈。金句：「實體資產躍上區塊鏈，全天候交易零時差！」

  - 代幣化美債 (Tokenized Treasury)：例如 BlackRock 發行的 BUIDL，持有即享美債收益。金句：「手上握有代幣，就能坐收傳統國債的利息！」

  - 預言機 (Oracle)：安全傳遞鏈外真實世界價格與資料至區塊鏈上。金句：「區塊鏈穿透現實的眼睛，即時傳遞真實價格！」

  - 清算與結算 (Liquidation & Settlement)：透過智能合約實現自動化與高效率交割。金句：「鏈上自動結算，大幅省去傳統繁複的人工手續！」

  - 💡 學習教室：

    * RWA (Real World Assets)：把股票、債券等實體資產代幣化搬到區塊鏈上。

    * 代幣化 (Tokenization)：將實體資產的所有權或價值轉換成鏈上數位代幣。

    * 預言機 (Oracle)：將現實世界數據安全導入區塊鏈智能合約的橋樑。

【主題四：可程式化金融、AI Agent 與前沿技術】

* 正面：AI 也懂得自己刷卡買東西？解密未來可程式化金融與鏈上支付！(Icon: 🤖)

* 背面：

  - 可程式化金融：將金融服務拆成模組，利用智能合約實現自動化支付。金句：「讓資金會自己思考，按條件自動扣款無須人工干預！」

  - AI Agent 鏈上支付：AI 代理人自主執行任務，並透過微支付協議（如 x402）以穩定幣直接結算。金句：「AI 代理人的專屬錢包，開啟微支付自動化新時代！」

  - 零知識證明 (Zero-Knowledge Proof)：在不洩漏具體隱私資料的情況下，證明某件事為真。金句：「隱私不洩漏，驗證依然真！」

  - Code is Law (程式碼即法律)：DeFi 的核心精神，合約程式碼如何撰寫即如何執行。金句：「靠合約邏輯代替人情運作，自動執行最公正！」

  - 💡 學習教室：

    * AI Agent (AI 代理人)：能自主拆解任務、執行與判斷的 AI 程式。

    * x402 協議：基於 HTTP 402 狀態碼，讓 AI 直接用穩定幣付費的標準協議。

    * 零知識證明：在不暴露背後具體數據的情況下，證明某項陳述確實為真。

### 📝 第二階段：互動式單元總測驗

在網頁底部設計一個「挑戰區塊鏈小學堂」測驗系統。共 5 題（單選題），點選後要立刻顯示該題對錯與綠色解析文字。

* Q1. 哪一種穩定幣是以現金或短期美債作為 1:1 儲備資產？

  選項：(A) 演算法穩定幣 (B) 法幣抵押型穩定幣 (C) 合成美元穩定幣 (D) 槓桿型穩定幣

  👉 答案：(B)

* Q2. 什麼是穩定幣的「脫鉤 (Depeg)」？

  選項：(A) 穩定幣交易速度變慢 (B) 穩定幣價格偏離原本錨定的價格 (C) 手續費大幅上升 (D) 交易所暫停出入金

  👉 答案：(B)

* Q3. 美國通過的支付型穩定幣聯邦專法名稱為何？

  選項：(A) MiCA (B) CLARITY Act (C) GENIUS Act (D) Dodd-Frank Act

  👉 答案：(C)

* Q4. 什麼是 RWA（真實世界資產）？

  選項：(A) 僅存於虛擬世界中的遊戲道具 (B) 將股票、債券等傳統資產代幣化搬上區塊鏈 (C) 一種新的演算法穩定幣 (D) 區塊鏈的硬體設備

  👉 答案：(B)

* Q5. 專門讓 AI Agent 透過 HTTP 請求直接以穩定幣完成付費的標準協議為何？

  選項：(A) x402 協議 (B) MP3 協議 (C) SMTP 協議 (D) IPFS 協議

  👉 答案：(A)
